# M276 Сканер

Сканер-логгер для Mercedes C 300 4MATIC (W204, M276) через адаптер OBDLink CX (Bluetooth LE).
Открывается на iPhone в браузере Bluefy (Web Bluetooth).

- Живые данные: обороты, скорость, дроссель, нагрузка, угол зажигания, ДМРВ, температуры, лямбда по рядам, коррекции топлива
- Предупреждения: бедная смесь на полном газу, провал угла, коррекции больше ±10%
- Запись лога в CSV, VIN / Calibration ID / CVN, коды ошибок
- Только чтение: команды записи и стирания заблокированы
- Демо-режим без машины
